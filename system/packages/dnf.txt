# dnf-Pakete für Fedora 44 + Hyprland 0.56 + Quickshell (Stand 2026-10-20)
# Quelle der Wahrheit: der laufende PC (`rpm -q`, `dnf history` ab ID 14 = selbst installiert, `dnf repoquery --installed --qf '%{name} %{reason}'`).
# `dnf repoquery --userinstalled` liefert ~400 Einträge, weil das Kiwi-Image fast alles als "User" markiert – Basis-Rauschen.
#
# Format: ein Paket pro Zeile, "# …" = Kommentar.
#   paket     installieren
#   -paket    entfernen (dnf remove)
#   ?paket    optional / nicht mehr nötig: bootstrap zeigt nur einen Hinweis; installiert wird nur mit --optional
# system/bootstrap installiert alles Fehlende in EINEM `dnf install` (idempotent). Basis (Kernel, systemd, NetworkManager …)
# bringen Fedora Workstation und Fedora KDE selbst mit und steht deshalb nicht hier.
