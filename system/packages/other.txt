## System (/etc, root) – vom Bootstrap mit sudo
- Gruppe kvm für den eigenen Benutzer (Claude Desktop VM)       sudo usermod -aG kvm $USER
- Gruppe pkg-build für den eigenen Benutzer (lpf baut Spotify)      sudo usermod -aG pkg-build $USER
- Modul vhost_vsock beim Boot                          /etc/modules-load.d/vhost_vsock.conf
- /etc/containers/nodocker (podman-docker ohne Hinweis)
- Anmeldung: Plasma Login Manager (plasmalogin.service ist display-manager); auf Workstation wechselt bootstrap 3 von GDM darauf
- Firewall: Dienst rdp freigegeben (nur wenn krdp installiert ist – Plasma)
- Wake-on-LAN: nmcli connection "Wired connection 1" 802-3-ethernet.wake-on-lan magic
- Secure Boot an → akmods-Schlüssel per MOK einschreiben (manuell, Neustart)
- Kernel-Zeile (kommt von akmod-nvidia/grubby): rd.driver.blacklist=nouveau,nova_core modprobe.blacklist=nouveau,nova_core
- Login-Bildschirm: scripts/loginscreen apply (sudo, eigener Schritt im Repo, nur als Hinweis in bootstrap 10)
Nicht mehr nötig: Chrome-Repo/Brave-Repo (siehe repos.txt), KWin-Shell-Paket (~/.local/share/plasma/shells/de.bastian.desktop, nur --kwin)
